The customer opens their balance. Pointer physics say it is a hand; the endpoint returns the data.

Built for the session, not the door

Bot management stops bots before login. Enterprise browsers watch employees. Neither sees the agent a legitimate customer invites into their own account. NanoTarget works inside the session, at the endpoint that returns the data.

Detected at attach time

Agent tools leave traces the instant they take control — overlay markers, injected globals, evaluated-script reads, focus emulation, signed requests. Seen 0.1–0.5 s after attach, before the first action.

Pointer physics per click

A hand’s path is curved, its tremor grows with speed, it slows onto the target and holds 83–225 ms. Drivers teleport and release in 1–4 ms; generated curves are parabola-clean. A boosted-tree model, AUC 0.999, zero human false positives.

Policy per endpoint

allow · mask · step_up · block per resource, in your JSON. Masking is your function. Decisions are made on your server and written to a hash-chained audit log.

Seal on attach

Data already on screen is redacted in the browser the instant an indicator appears. The agent’s read sees •••• — even a read already in flight.

Passkey reclaim

Once an agent attached, the session stays “agent” until the person proves presence with WebAuthn — Touch ID, Windows Hello — and takes it back for five minutes.

Observe first, enforce later

Start in observe: nothing is blocked, every decision is recorded with what would have happened. Review the log, then flip one word.

How it tells a hand from a program

Integrate in an afternoon — or let your coding agent do it

The npm README is written for AI coding agents: give it the link and say “install this”. It scans your app, maps what an agent could reach, proposes what to gate, asks you nine questions and wires everything in.

// three lines
import { nanotarget } from 'nanotarget/express';

const nt = await nanotarget({ secret: process.env.NT_SECRET, policy: './nanotarget.policy.json',
                              db: 'sqlite:./nanotarget.db', identify: (req) => req.session?.userId ?? null });
app.use(nt.middleware());                                              // serves /nanotarget/sdk.js + its API
app.get('/api/balance', nt.protect('balance.read'), (req, res) => nt.send(req, res, balance, maskBalance));
