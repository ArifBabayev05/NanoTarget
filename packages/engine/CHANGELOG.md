# Changelog — nanotarget-engine

This package is released together with [`nanotarget`](https://www.npmjs.com/package/nanotarget) at the same version; its changes are listed in that package's CHANGELOG. You install `nanotarget`, not this.

## 0.5.0 — 2026-09-24
- Exports `ENGINE_VERSION`; `nanotarget` checks it at startup and refuses a mismatched pair with an actionable message.

## 0.4.0 — 2026-09-24
- First release as a separate package (Business Source License 1.1). Before 0.4.0 the engine was bundled inside `nanotarget` under MIT.
